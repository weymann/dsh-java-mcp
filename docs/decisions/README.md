# Decision Records

Short, dated records of non-trivial decisions. One file per decision,
sequentially numbered: `NNNN-kebab-case-title.md`.

Each record contains:

1. **Context** – starting point, constraints, alternatives.
2. **Decision** – what applies, including concrete values (versions, fields).
3. **Consequences** – what follows, including limits and risks.

Records are not rewritten after the fact. If a decision changes, a new record
supersedes the old one.
